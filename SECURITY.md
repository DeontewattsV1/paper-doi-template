# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Current files on `main` | Yes |
| Older commits | No |
| Paper repositories created from this template | No |

This repository is a manuscript template. It does not run a service. Fixes land on the default branch. A repository created with **Use this template** is a separate project and is outside this policy.

## Reporting a vulnerability

Report security issues by email to deonte@goodshyt.fun.

Include the repository name, what you found, and how to reproduce it. Do not open a public issue for an undisclosed vulnerability.
